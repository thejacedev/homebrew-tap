# thejacedev Homebrew tap

[Homebrew](https://brew.sh) cask for [Noteriv](https://github.com/thejacedev/Noteriv), the open-source markdown editor.

```bash
brew install --cask thejacedev/tap/noteriv
```

Update with `brew upgrade --cask noteriv`.

The app is not yet notarized by Apple, so macOS may block the first launch. If it does, open System Settings → Privacy & Security and choose "Open Anyway".
